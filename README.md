**ESP8266 8x32 Matrix - Happy New Year**

Fun implementation of Aaron Liddiment's LEDText library with New Year 2022 greeting.

All credit to:
https://github.com/AaronLiddiment/LEDText. Really nice work!

An 8x32 WS2812B ("NeoPixel") panel mounted on cardboard, with a sheet of 8.5x14 paper as a diffuser. Throw in a Wemos D1 mini ESP8266, a few jumpers, a capacitor that's probably not needed, and code from GitHub and voila! You have a fun New Years display.
